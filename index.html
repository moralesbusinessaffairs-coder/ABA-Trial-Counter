Quick Start & How to Use
  1. Tap + Add Program and enter the replacement programs you need to run.
  2. Tap a program card to make it active.
  3. For each trial, tap Positive or Negative.
  4. Each program stops automatically at 10/10 trials.
  5. Use Undo Last Trial if the most recent entry was incorrect.
  6. Review the day’s data, then use Clear Daily Data when you are ready to start fresh. The program list remains saved.

General notes

Privacy: program names and the current daily trial data are stored in this browser’s local site storage until you use Clear Daily Data. The app does not send session data to a server. Do not enter client names, initials, dates of birth, or other identifying information. Clearing browser/site data or removing the app may also remove locally stored data.
